---

### [普通方程：一个未知数] (理论篇 P16)
- **【核心公式/模型】**：找等量关系，设未知数 $x$，列方程求解。
- **【判定特征词】**：题目中有明显的等量关系，如“共”、“比...多/少”、“是...的几倍”。
- **【秒杀技巧/口诀】**：
  - **设小不设大**：尽量把较小的量设为 $x$，避免计算中出现分数。
  - **出现比例设份数**：看到甲乙之比为 $3:4$，直接设甲为 $3x$，乙为 $4x$。
  - **设中间量**：当多个量相互比较时，把处于中间环节的量设为 $x$（如甲比乙多，乙比丙多，设乙为 $x$）。
- **【全网/2026最新解法补充】**：
  - **选项代入法**：如果题目只问一个主体的量，且方程列出来比较复杂（如分式方程），**绝对不要硬解**，直接把选项代入题干验证，谁能让条件成立就选谁。
- **【易错反例】**：设的未知数 $x$ 不是题目最终要求的值。解出 $x$ 后激动地直接选了对应选项，**忘记进行最后一步换算**（出题人最喜欢把中间变量 $x$ 的值放在A选项挖坑）。
- **【实战应用提醒】**：难度★，考频极高。**蒙题方向**：结合选项的倍数、奇偶性蒙。例如设了 $3x$，直接在选项找3的倍数。

### [普通方程组：多个未知数] (理论篇 P17)
- **【核心公式/模型】**：存在多个未知数，设 $x, y, z$，列出多个方程。
- **【判定特征词】**：题目中出现多个主体，且给出了多个等量关系。
- **【秒杀技巧/口诀】**：**抓住问题，消元求解**。
  - 绝大多数公考方程组**不需要求出每一个未知数**。观察最终要求的是什么（如求 $x+y$），直接通过两个方程相加或相减进行“整体代换”。
- **【全网/2026最新解法补充】**：
  - **配凑法（全网通用）**：求什么配什么。例如已知 $x+2y=5$ 和 $2x+y=4$，求 $x+y$。直接将两式相加得到 $3x+3y=9$，化简即得 $x+y=3$。
- **【易错反例】**：陷入“死算”陷阱，非要按部就班把 $x, y, z$ 全部分别解出来，白白浪费2分钟。
- **【实战应用提醒】**：难度★★，考频高。**蒙题方向**：如果题目问 $x+y+z$ 的总和，且系数有规律，答案往往是某个特定数字的倍数。

### [不定方程] (理论篇 P18-19)
- **【核心公式/模型】**：$ax + by = M$ （未知数个数多于方程个数，通常隐含 $x, y$ 为正整数的条件）。
- **【判定特征词】**：题目中出现“若干”、“买了几件”、“各多少人”，且未知数在现实中**必须是整数**。
- **【秒杀技巧/口诀】**：**奇偶、倍数、尾数、代入**。
  - **① 奇偶特性**：如 $3x + 4y = 25$。因为 $4y$ 必为偶数，25是奇数，所以 $3x$ 必为奇数 $\rightarrow$ $x$ 必为奇数。
  - **② 倍数特性**：如 $7x + 3y = 60$。因为 $3y$ 和 60 都是3的倍数，所以 $7x$ 必是3的倍数 $\rightarrow$ $x$ 必是3的倍数。
  - **③ 尾数法**：当系数有 5 或 10 时。如 $37x + 20y = 271$。因为 $20y$ 尾数必为0，所以 $37x$ 尾数必为1 $\rightarrow$ $x$ 的尾数必为3。
- **【全网/2026最新解法补充】**：
  - **同余消元法（花生十三推荐）**：针对系数互质且不好找倍数的情况。例如 $7x+3y=60$，两边同时除以较小的系数3，得到余数方程：$1x + 0 = 0 \rightarrow x$ 必须是3的倍数。
- **【易错反例】**：忘记考虑“0”的情况。题目说“若干”一般不含0（至少为1）；如果题目说“可以不买”或“最多/最少”，则必须考虑未知数取0的边界情况。
- **【实战应用提醒】**：难度★★，考频极高。**蒙题方向**：不定方程**首选代入排除法**！把选项代入方程，只要能解出另一个未知数也是正整数，直接秒选。

### [不定方程组] (理论篇 P20-22)
- **【核心公式/模型】**：两个方程，三个未知数。$\begin{cases} a_1x + b_1y + c_1z = M \\ a_2x + b_2y + c_2z = N \end{cases}$
- **【判定特征词】**：三种物品（甲乙丙），给了两组总价/总数，求某一种或某几种的组合（如求 $x+y+z$）。
- **【秒杀技巧/口诀】**：
  - **考法一（未知数一定是整数）**：先消元，消去题目不问的那个未知数，转化为两个未知数的“不定方程”，再用奇偶/倍数/尾数法解。
  - **考法二（未知数可以是小数，如单价/时间）**：**赋零法**。直接令其中1个未知数为0，把方程组变成普通的二元一次方程组，快速解出另外两个未知数，直接求和。（有理有据，有推有导）。
- **【全网/2026最新解法补充】**：
  - **粉笔“特值法”**：在求整体组合（如 $x+y+z$）时，直接令**系数最复杂或最大的那个未知数为0**，这样计算量最小。
- **【易错反例】**：在未知数**必须是整数**（如人数、件数）的题目中强行使用“赋零法”，导致解出小数或负数，无法对应选项。**赋零法仅适用于求整体组合且无整数限制，或恰好赋0能解出整数的情况。**
- **【实战应用提醒】**：难度★★★，考频中等。**蒙题方向**：看到求 $x+y+z$，直接用赋零法算，算出来是多少选项就选多少，不要怀疑自己。

### [A和非A思想在数量中的运用] (拔高篇 P18)
- **【核心公式/模型】**：$A = \frac{\text{非}B + \text{非}C - \text{非}A}{2}$。
- **【判定特征词】**：题目中出现排比句式：“有 $x$ 件不是甲的，有 $y$ 件不是乙的，有 $z$ 件不是丙的”。
- **【秒杀技巧/口诀】**：
  - **总数秒杀公式**：$总数 = \frac{\text{非甲} + \text{非乙} + \text{非丙}}{2}$。
  - 求出总数后，**甲 = 总数 - 非甲**。
- **【全网/2026最新解法补充】**：
  - 这本质上是容斥原理的变形。因为“非甲”其实就是“乙+丙”。所以 非甲+非乙+非丙 = (乙+丙) + (甲+丙) + (甲+乙) = 2(甲+乙+丙) = 2倍总数。理解了这个逻辑，再多主体（如4个）也能推导：总数 = 所有“非”之和 $\div 3$。
- **【易错反例】**：死记硬背公式，遇到4个主体时依然除以2。记住规律：**除数 = 主体数 - 1**。
- **【实战应用提醒】**：难度★★，考频低（属于特定题型秒杀）。**蒙题方向**：把题目给的三个“不是”的数字加起来除以2得到总数，然后减去对应的数字即为答案。

### [方程中的排比句 (盈亏问题)] (拔高篇 P19-21)
- **【核心公式/模型】**：每人分 $a$ 个剩 $x$（盈），每人分 $b$ 个缺 $y$（亏）。
- **【判定特征词】**：句式高度对称：“如果...则（剩/多）...；如果...则（缺/少）...”。
- **【秒杀技巧/口诀】**：
  - **盈亏公式**：**人数（对象数） = $\frac{\text{盈} + \text{亏}}{\text{两次分配差}}$**。
  - 物品总数 = 人数 $\times$ 分配数 + 盈（或 - 亏）。
- **【全网/2026最新解法补充】**：
  - **倍数特性秒杀**：如果题目问物品总数，且条件是“每人分5个剩2个”，说明 $(总数 - 2)$ 是5的倍数，直接看选项哪个减2能被5整除。
- **【易错反例】**：遇到“多一步”的排比句不会转化。例如：“如果每辆小车少坐1人，则有8人没坐上车”。必须先转化为标准句式：“如果每辆小车坐4人（假设原定5人），则多出8人（盈）”，然后再套公式。
- **【实战应用提醒】**：难度★★，考频中等。**蒙题方向**：优先使用倍数特性代入选项，90%的盈亏问题不需要列方程就能选出答案。

### [鸡兔同笼] (拔高篇 P22)
- **【核心公式/模型】**：
  - 兔数 = $\frac{\text{实际脚数} - \text{每只鸡脚数} \times \text{总头数}}{\text{兔脚数} - \text{鸡脚数}}$。
- **【判定特征词】**：两种事物，两个总数（头数、脚数）；或者考试计分题“答对得 $x$ 分，不答或答错扣 $y$ 分”。
- **【秒杀技巧/口诀】**：**假设法**。
  - 假设全是鸡，算出理论脚数，与实际脚数作差。这个差值是因为把兔当成了鸡，每只兔少算了（兔脚-鸡脚）。除以脚数差，就是兔的数量。
- **【全网/2026最新解法补充】**：
  - **奇偶特性秒杀（极快）**：例如 $50x + 45y = 1290$（总分），$x+y=27$（总题数）。因为1290是偶数，50x是偶数，所以45y必是偶数 $\rightarrow$ $y$ 必是偶数。又因为 $x+y=27$（奇数），所以 $x$ 必是奇数。直接看选项选奇数。
  - **十字交叉法**：鸡的平均脚数2，兔的平均脚数4，混合平均脚数（总脚数/总头数），交叉作差直接得出鸡兔数量比。
- **【易错反例】**：在“答错扣分”题型中，**脚数差算错**。例如答对得3分，答错扣2分。此时的“脚数差”是 $3 - (-2) = 5$ 分，而不是 $3 - 2 = 1$ 分！
- **【实战应用提醒】**：难度★，考频中等。**蒙题方向**：如果是考试计分题，直接用奇偶特性判断答对题数的奇偶性，排除两个选项后代入验证。
